# Метрики автоматизаций

## Базовый стандарт
Для каждой автоматизации по возможности фиксировать:
- объём операций в месяц;
- ручное время до;
- автоматическое время после;
- экономию времени;
- долю автоматизированных операций;
- количество ошибок;
- SLA / скорость выполнения;
- стоимость инфраструктуры;
- экономический эффект.
