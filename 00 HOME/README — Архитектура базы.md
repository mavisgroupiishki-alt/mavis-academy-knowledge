# Что настроил скрипт

Скрипт создаёт и нормализует базовую архитектуру `Mavis Knowledge`.

## Что делает
1. Создаёт отсутствующие папки.
2. Переименовывает одиночные `INDEX.md` в уникальные INDEX-файлы, если это безопасно.
3. Создаёт главную страницу.
4. Создаёт шаблоны.
5. Создаёт базовые связанные сущности для первого проекта.
6. Не удаляет существующие заметки.
7. Перед изменениями создаёт резервную ZIP-копию vault рядом с vault.

## Что скрипт намеренно НЕ делает
- не устанавливает сторонние Obsidian-плагины;
- не меняет пароли, API-ключи и токены;
- не подключается к Bitrix/GitHub/Drive;
- не удаляет пользовательский контент;
- не меняет системные настройки macOS.

Эти шаги лучше подключать отдельно после проверки структуры.
