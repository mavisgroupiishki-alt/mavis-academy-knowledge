# PROMPT — Обновить документацию проекта

Используй текущую карточку проекта, последние изменения кода и связанные системные заметки.

Нужно:
1. определить, что реально изменилось;
2. обновить только затронутые разделы;
3. добавить запись в историю изменений;
4. не придумывать отсутствующие факты;
5. отметить неизвестные данные как TODO;
6. не раскрывать секреты и токены.
