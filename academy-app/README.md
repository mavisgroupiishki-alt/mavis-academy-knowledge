# Mavis Academy · MVP

Рабочий демонстрационный интерфейс в `academy-app/`. Источник уроков — заметки `03 SALES` из того же репозитория; API `/api/knowledge/status` проверяет свежий коммит GitHub (кеш 5 минут). **Курсы пока статические, изменения в Obsidian сами по себе НЕ переписывают уроки.**

## Запуск
`python3 academy-app/server.py` из корня репозитория. Порт берётся из переменной `PORT` (по умолчанию 10000).

## Render
- Новый Web Service из данного репозитория, **не изменяя** другие сервисы.
- Runtime `Python`, план `Free`, регион `Frankfurt`.
- Build command: `echo 'No dependencies'`
- Start command: `python3 academy-app/server.py`
- Auto deploy: `No` — чтобы каждый коммит заметок Obsidian не перезапускал сайт.
- Health path: `/healthz`.

## Ограничения
Пилот включает 7 уроков, 7 тестовых вопросов, карточки и мини-кроссворд. Прогресс хранится только в localStorage. Авторизация, Supabase, генерация видео, ИИ-сборка обновлённых уроков, ежемесячное тестирование и реальная аналитика сотрудников **не реализованы**. Не вводите в MVP персональные данные и реальные результаты аттестаций. Некоторые импортированные заметки имеют `needs_review` и должны быть утверждены руководителем.
