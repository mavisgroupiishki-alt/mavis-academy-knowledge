# Mavis Academy · v2

Обновлённая версия интерфейса обучения.

## Что изменено
- новый более яркий визуальный стиль: тёмный фон + акцентные оранжевый / синий / розовый;
- только 3 направления: продажи, эксперты, Bitrix24;
- каждый день вынесен в отдельную плитку;
- день рассчитан минимум на 2 часа;
- внутри дня есть видеоблок, теория, чек-лист, кейс, практические задания и тест на 5 вопросов;
- убраны маркетинг и раздел для руководства;
- убрана пометка «источник требует проверки».

## Запуск
```bash
python3 academy-app/server.py
```

## Render
- Runtime: Python
- Build command: `echo 'No dependencies'`
- Start command: `python3 academy-app/server.py`
- Auto deploy: `No`
- Health path: `/healthz`

## Важно
Полностью детализирован сейчас курс отдела продаж. Для экспертного отдела и Bitrix24 уже сделан полный каркас курса и формат дня; дальше можно донасыщать контент из базы знаний в той же логике.
