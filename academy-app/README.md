# Mavis Academy v3 — интерактивная стажировка

Только 3 направления: продажи, эксперты, Bitrix24.

Новая структура: текст в небольших блоках, упражнения между блоками, интерактивные сопоставления, самостоятельные ответы в самой платформе, игра на порядок действий, терминологическая головоломка, финальный кейс. При ошибке показывается подсказка с указанием, какой фрагмент повторить. Прогресс хранится в localStorage браузера.

Никаких заявлений о фиксированной норме обучения в часах нет.

Для видеоблока реализована интерактивная слайд-лекция с озвучиванием посредством Web Speech API браузера. Полноценные записанные видеоролики пока не созданы. Озвучивание зависит от голосов и настроек конкретного устройства.

День для продаж наполнен подробнее, для экспертов и Bitrix24 — несколько базовых обучающих дней с предметным материалом. Данные сотрудников и результаты пока централизованно не сохраняются. Сервис не предназначен для итоговой корпоративной аттестации без аккаунтов, БД и системы проверки.

Render запускается прежней командой: `python3 academy-app/server.py`. Автоматические деплои по-прежнему можно держать выключенными.
