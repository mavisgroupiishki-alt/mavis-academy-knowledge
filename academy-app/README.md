# Mavis Academy 4.0 — продажи по плану адаптации

Источники: присланная таблица `Стажировка Отдел Продаж.xlsx` (4 рабочих дня), паспорта СПК/аттестации/ISO, материалы `03 SALES` из Obsidian/GitHub. 

## Изменения
- Продажи: 4 дня по исходному плану. 48 обучающих блоков: подробная теория, 4 настоящих коротких MP4 с русской синтетической озвучкой, вопросы, сопоставления, задания на порядок, письменные ответы, мини-экзамены. Видео пока короткие и с технической озвучкой — не полноценные 20-минутные профессиональные лекции.
- Полные текстовые паспорта и скрипты читаются **внутри платформы** через `/api/knowledge/document`; при просмотре нужен интернет к публичному GitHub.
- Письменный ответ сохраняется локально и проходит простую проверку по смысловым пунктам. Это **не** AI-оценка. Для AI-оценки предусмотрен защищённый серверный маршрут `/api/ai/grade`, который начнёт обращаться к модели только после настройки переменных окружения.
- Направления экспертов и Bitrix24 сохранились из предыдущей версии.

## Настройка AI-проверки на Render
В отдельном сервисе `mavis-academy` установить:
- `ACADEMY_AI_TOKEN` — секретный ключ API провайдера;
- `ACADEMY_AI_URL` — полный URL OpenAI-совместимого chat completions endpoint (если не задан, используется `https://api.openai.com/v1/chat/completions`);
- `ACADEMY_AI_MODEL` — идентификатор доступной модели (по умолчанию `gpt-4.1-mini`).

**Не помещать ключ в `app.js`, `index.html` или Obsidian.** Без этих переменных работает учебная проверка по ключевым смысловым блокам и честно показывает, что AI пока не подключён.

## Размещение
Распаковать архив в корень хранилища `Mavis Knowledge/Mavis Knowledge` с заменой файлов `academy-app`, затем закоммитить и отправить GitHub. На Render (сервис `mavis-academy`, автодеплой отключён) выполнить Manual Deploy → Deploy latest commit.

Backend: `python3 academy-app/server.py`, Python стандартная библиотека, PORT из окружения.
