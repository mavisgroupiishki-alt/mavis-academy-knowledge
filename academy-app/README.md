# Mavis Academy 4.0 — продажи по плану адаптации

Источники: присланная таблица `Стажировка Отдел Продаж.xlsx` (4 рабочих дня), паспорта СПК/аттестации/ISO, материалы `03 SALES` из Obsidian/GitHub. 

## Изменения
- Продажи: 4 дня по исходному плану. Подробная теория, вопросы, сопоставления, задания на порядок, письменные ответы и мини-экзамены. Нерабочие видеоуроки удалены: вместо них в программу встроены текстовые разборы с практическими правилами.
- «Рабочая база» для действующих менеджеров: 40 материалов из вкладки «Продажи» навигатора, разложенных по 7 разделам. В базе есть поиск, фильтры «изучено / не изучено», расположение каждого материала и переход к существующим проверкам знаний. Прогресс пока хранится локально в браузере; его нельзя использовать как отчёт руководителя по сотрудникам.
- В рабочей базе есть помощник: он находит относящиеся к вопросу фрагменты учебных материалов, отвечает с отдельными источниками «Внутренняя база Mavis» и «Открытые источники · Беларусь». Для текущих требований по РБ используется веб-поиск; открытые сведения не смешиваются с внутренними инструкциями. Вопросы и ключ не сохраняются в браузере.
- У каждого из 7 разделов есть сложная практика: кейс с выбором действия, соотнесение понятий и порядок действий. Результат сохраняется только в браузере менеджера.
- Полные текстовые материалы читаются **внутри платформы** через защищённый `/api/course/document`: сервер проверяет роль сотрудника и разрешённый маршрут курса. Для работы с исходниками нужен доступ сервера к публичному GitHub.
- Письменный ответ сохраняется локально и проходит простую проверку по смысловым пунктам. Это **не** AI-оценка. Для AI-оценки предусмотрен защищённый серверный маршрут `/api/ai/grade`, который начнёт обращаться к модели только после настройки переменных окружения.
- Направления экспертов и Bitrix24 сохранились из предыдущей версии.

## Настройка AI-помощника и проверки на Render
Для проверенной конфигурации OpenRouter в сервисе `mavis-academy` установить:
- `ACADEMY_AI_PROVIDER=openrouter` (по умолчанию);
- `ACADEMY_AI_TOKEN` — секретный ключ OpenRouter;
- `ACADEMY_AI_URL=https://openrouter.ai/api/v1/chat/completions`;
- `ACADEMY_AI_MODEL=openai/gpt-6.1-terra` (или другую проверенную и доступную в аккаунте модель).

Поиск по открытым источникам ограничен одной поисковой операцией и тремя результатами на запрос. Другие режимы можно выбрать через `ACADEMY_AI_PROVIDER=gemini` или `openai-compatible`; провайдерские ограничения и адреса нужно настраивать отдельно.

**Не помещать ключ в `app.js`, `index.html` или Obsidian.** Без этих переменных работает учебная проверка по ключевым смысловым блокам и честно показывает, что AI пока не подключён.

## Постоянное сохранение правок руководителя

Редактор материалов, плиток стажировки и каталога использует существующее Supabase-хранилище результатов (`mavis_dashboard_kv`). На Render должны быть заданы серверные секреты `ACADEMY_RESULTS_URL` и `ACADEMY_RESULTS_SERVICE_KEY`; они же используются для сохранения правок. При необходимости можно указать отдельную пару `ACADEMY_STATE_URL` и `ACADEMY_STATE_SERVICE_KEY`.

Не устанавливайте `ACADEMY_ALLOW_LOCAL_STATE` на Render: этот режим предназначен только для локальной разработки. Если постоянное хранилище недоступно, Academy вернёт ошибку сохранения, а не будет сообщать о сохранении, которое пропадёт после перезапуска.

## Размещение
Распаковать архив в корень хранилища `Mavis Knowledge/Mavis Knowledge` с заменой файлов `academy-app`, затем закоммитить и отправить GitHub. На Render (сервис `mavis-academy`, автодеплой отключён) выполнить Manual Deploy → Deploy latest commit.

Backend: `python3 academy-app/server.py`, Python стандартная библиотека, PORT из окружения.
