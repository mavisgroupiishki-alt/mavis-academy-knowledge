# План

1. Проверить покрытие всех плиток менеджера и эксперта подключёнными файлами.
2. Убрать отображение статичных пересказов из ролевого читателя.
3. Оставить структуру плитки: понятие → специалисты → инструменты и СИ → ход
   работы → другое, где каждый фактический блок строится по источнику.
4. Расширить стили ролевого читателя и проверить JavaScript, тесты и ссылки на
   локальные источники.
