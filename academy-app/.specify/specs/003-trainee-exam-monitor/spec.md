# Спецификация: маршрут стажёра, итоговая аттестация и доступность Academy

**ID:** 003-trainee-exam-monitor
**Статус:** Approved
**Создана:** 2026-11-06

## Цель

Сделать путь стажёра понятным по четырём рабочим дням, добавить защищённую итоговую аттестацию и обеспечить регулярную проверку доступности Academy.

## Пользовательские истории

- Как стажёр, я хочу видеть, что именно открыть в каждом из четырёх дней, а не неопределённую кнопку «Продолжить обучение».
- Как стажёр, я хочу пройти сложную итоговую аттестацию после изучения программы и увидеть свой результат.
- Как стажёр, я хочу получить новый вариант экзамена только после завершения текущей попытки.
- Как руководитель, я хочу видеть результаты всех упражнений и экзаменов стажёров и их итоговую оценку.
- Как владелец Academy, я хочу, чтобы отдельный монитор регулярно проверял доступность публичного сервиса.

## Функциональные требования

1. Для роли стажёра Academy ДОЛЖНА показывать четыре кликабельных дня, каждый с конкретными темами, ожидаемым результатом и кнопкой открытия следующего действия.
2. Для стажёра ДОЛЖНА быть отдельная вкладка «Итоговая аттестация», а кнопка в боковом меню ДОЛЖНА называться «Следующий шаг» и объяснять, какой материал будет открыт.
3. Итоговая аттестация ДОЛЖНА содержать несколько сложных заданий по продуктам, диагностике, следующему шагу и CRM-логике.
4. Новый вариант итоговой аттестации ДОЛЖЕН быть недоступен до завершения текущей попытки; после завершения он ДОЛЖЕН фиксировать новую попытку.
5. Попытки и результаты игр ДОЛЖНЫ сохраняться в постоянном серверном хранилище и отображаться руководителю по имени стажёра.
6. Оценка кандидата ДОЛЖНА включать прозрачный балл по заданиям и отдельное смысловое заключение AI, если провайдер AI настроен; при недоступном AI интерфейс ДОЛЖЕН показывать это честно, без фиктивной оценки.
7. Отдельный планировщик ДОЛЖЕН запрашивать `/healthz` Academy не реже одного раза в десять минут и завершаться ошибкой при неуспешном ответе.

## Вне скоупа

- Автоматическое создание учётных записей Supabase Auth для каждого имени из формы Academy.
- Выдача реальных доступов Bitrix24, запуск звонков или оценка реальных звонков в этой итерации.

## Критерии приёмки

- [ ] Стажёр открывает любой из четырёх дней и получает только материалы этого дня.
- [ ] «Следующий шаг» объясняет цель действия; «Продолжить обучение» больше не используется для стажёра.
- [ ] Итоговый тест нельзя перегенерировать до его завершения.
- [ ] Руководитель видит сохранённую попытку и балл стажёра.
- [ ] Планировщик проверяет публичный `/healthz` и имеет успешный тестовый запуск.
