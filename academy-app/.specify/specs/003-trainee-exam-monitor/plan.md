# Технический план: маршрут стажёра, итоговый экзамен и монитор

**Спека:** [spec.md](spec.md)
**Создан:** 2026-11-06

## Архитектура

`вход стажёра → день 1–4 → материалы и практика → итоговая аттестация → защищённая серверная запись попытки → кабинет руководителя`

`Render Cron → GET https://mavis-academy.onrender.com/healthz → успешный код / ошибка задания`

## Компоненты

- `manager-library.js`: явные карточки дней, отдельный экзаменационный экран, блокировка следующего варианта, кабинет руководителя.
- `server.py`: выдаёт/проверяет серверную сессию, валидирует и сохраняет попытки, отдаёт руководителю агрегированный список результатов.
- Supabase: постоянное хранение профиля и результатов с закрытым серверным доступом; клиент не получает service key.
- Render Cron: отдельный Python-процесс каждые десять минут обращается к `/healthz`.

## Риски и ограничения

- В существующем Supabase есть таблицы результатов, но Academy сейчас не авторизуется в Supabase. Для серверной записи потребуется закрытый service key в Render; не помещать его в Git или браузер.
- AI-проверка возможна только с уже настроенным серверным токеном провайдера. Без него сохраняется объективный балл, а не выдуманный AI-вывод.

## Проверка конституции

- [ ] Маршрут показывает материал внутри Academy.
- [ ] Роли и ключи остаются на сервере.
- [ ] Каждая попытка имеет проверяемый результат и не зависит от localStorage.
