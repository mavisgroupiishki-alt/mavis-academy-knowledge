# DEC-2026-003 — GitHub является источником правды по коду

## Решение
После миграции код автоматизаций хранится в GitHub, а Obsidian содержит описание, архитектуру и ссылки.

## Почему
Это разделяет знания и исполняемый код, даёт версии и позволяет безопасно сопровождать проекты.
