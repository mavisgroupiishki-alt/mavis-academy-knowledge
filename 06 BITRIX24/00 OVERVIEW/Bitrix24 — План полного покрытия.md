# Bitrix24 — план полного покрытия

- CRM: сделки, компании, контакты, лиды, товары, поля и справочники.
- CRM-активности: письма, звонки, встречи, коммуникации и ссылки на файлы.
- Задачи, группы, структура компании, шаблоны и экземпляры бизнес-процессов.
- Полные определения 50 шаблонов БП: привязки, параметры, переменные и структура шагов.
- Файловые хранилища: метаданные папок и файлов.
- Универсальные списки и реестры процессов.

Подробные агрегаты — в [[06 BITRIX24/00 OVERVIEW/Bitrix24 — Статус импорта 2026-10-12|статусе импорта]].

## Очередь read-only снимков

1. **Встроенные роботы CRM/задач:** в REST API Bitrix24 через webhook они не выдаются. Нужен отдельный read-only экспорт из административного интерфейса или штатного бэкапа портала; не путать с полными шаблонами БП, которые уже сохранены.
2. **CRM-автоматизация:** application-триггеры требуют контекст приложения и не заменяют настройки встроенных роботов; сохранить только доступную через REST схему.
3. **Телефония и звонки:** метаданные 185 978 звонков сохранены отдельным read-only снимком. Сами аудиозаписи не копируются в vault и требуют отдельной оценки объёма и политики хранения.
4. **Групповой контур:** списки групп и участники, если права webhook это разрешают.
5. **Файловые хранилища:** повторный обход 25 временно недоступных хранилищ с записью причины недоступности; затем отдельное извлечение разрешённого текстового содержимого документов.

## Правила выполнения

- Все вызовы только read-only; никаких запусков роботов, бизнес-процессов, рассылок или изменения задач.
- Полные данные сохраняются в закрытый архив, а в Obsidian попадают навигация и агрегированные статусы.
- Неудачный доступ фиксируется как пробел покрытия, а не маскируется под пустой результат.
- После каждого нового снимка обновляется [[06 BITRIX24/00 OVERVIEW/Bitrix24 — Статус импорта 2026-10-12|статус импорта]] и локальный поисковый индекс для Mavis AI.
