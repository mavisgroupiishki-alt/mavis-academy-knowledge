ИНСТРУКЦИЯ
ИНСТРУКЦИЯ
Как настроить автоматическую выгрузку данных
из воронки Bitrix24 в Google-таблицу
1. Как работает схема
Сделка попадает на выбранную стадию
       ↓
Bitrix24 запускает робота «Исходящий вебхук»
       ↓
Робот отправляет данные на ссылку Google Apps Script
       ↓
Apps Script записывает новую строку в Google-таблицу
	

2. Что подготовить до начала
Google-аккаунт, в котором будет храниться таблица.
Право редактировать нужную воронку и настраивать CRM-роботов в Bitrix24.(быть админом в битрикс)
Название воронки и стадии, при переходе на которую должна выполняться выгрузка.
Решение: данные из новой воронки будут попадать в отдельную таблицу или в уже существующую.
Рекомендуемый вариант
Для отдельной воронки создать отдельную Google-таблицу. Так проще проверять работу и не смешивать разные процессы.
	

3. Создание Google-таблицы и получение её ID
В адресной строке открытой таблицы будет ссылка примерно такого вида:
https://docs.google.com/spreadsheets/d/1AbCdEfGh123456789/edit
	ID таблицы — часть между /d/ и /edit:
1AbCdEfGh123456789
	

Сохраните ID
Он понадобится при генерации и настройке кода Apps Script. Не копируйте всю ссылку — нужен только ID.
	

2
	Сгенерируйте код Apps Script с помощью ИИ
Программировать самостоятельно не требуется. Скопируйте готовый промпт ниже в ChatGPT или другой ИИ-сервис.
	

4. Промпт для генерации кода
Скопируйте промпт целиком
Ты — опытный разработчик Google Apps Script и интеграций Bitrix24.

Сгенерируй полностью готовый код Google Apps Script для веб-приложения, которое принимает GET- и POST-запросы от робота «Исходящий вебхук» Bitrix24 и записывает данные в Google-таблицу.

Требования к коду:
1. В начале кода должны быть настройки:
  - SPREADSHEET_ID — ID Google-таблицы (СЮДА ВСТАВИТЬ АЙДИ ГУГЛ ТАБЛИЦЫ)
  - SHEET_NAME — название воронки, по умолчанию «Лиды»; (СЮДА ВСТАВИТЬ НАЗВАНИЕ ВОРОНКИ)
2. Скрипт должен принимать параметры:
  - key;
  - company;
  - company_phone;
  - company_email;
  - contact;
  - contact_phone;
  - contact_email.
4. В таблице создать столбцы: (УКАЗАТЬ НУЖНЫЕ)
  - Дата передачи;
  - Компания;
  - Телефон компании;
  - Почта компании;
  - Контактное лицо;
  - Телефон контакта;
  - Почта контакта.
5. Если вкладки нет — создать её автоматически.
6. Не очищать и не перезаписывать существующие строки.
7. Телефоны записывать в текстовом формате, чтобы Google не удалял знак «+» и не менял номер.
8. Если знак «+» потерялся в URL, автоматически восстановить его для номера, начинающегося с цифры.
9. Добавить LockService, чтобы одновременно пришедшие запросы не конфликтовали.
10. Добавить защиту от одинаковых повторных запросов в течение 10 минут через CacheService.
11. Проверять SECRET_KEY. При неверном ключе возвращать текст «ERROR: неверный секретный ключ».
12. Если все поля пустые, не добавлять строку и возвращать «ERROR: данные клиента не переданы».
13. При успешной записи возвращать «OK: строка добавлена».
14. При ошибке возвращать понятный текст с причиной.
15. Код должен содержать функции doGet(e) и doPost(e), работать как опубликованное веб-приложение Apps Script и быть готовым к копированию целиком без дополнительных библиотек.
16. Добавь понятные русские комментарии в коде.
17. В ответе сначала дай только готовый код одним блоком, затем коротко укажи, какие три значения заменить перед публикацией.

Мои значения:
SPREADSHEET_ID: [ВСТАВЬТЕ ID ТАБЛИЦЫ]
SHEET_NAME: [ВСТАВЬТЕ НАЗВАНИЕ ВКЛАДКИ]

	

	





3
	Откройте Apps Script и вставьте код
	1. Вернитесь в созданную Google-таблицу.
2. Откройте «Расширения» → «Apps Script».
3. Удалите стандартный код function myFunction() { } целиком.
4. Вставьте код, который сгенерировал ИИ.
5. Нажмите Ctrl+S / Cmd+S.


  





4
	Опубликуйте Apps Script как веб-приложение
	1. В редакторе Apps Script нажмите «Развернуть» → «Новое развертывание».
2. Нажмите значок шестерёнки возле «Выберите тип» и выберите «Веб-приложение».
3. Описание: «Приём заявок из Bitrix24».
4. Выполнять от имени: «Я».
5. У кого есть доступ: «Все» 
6. Нажмите «Развернуть» и подтвердите разрешения Google.
7. Скопируйте URL веб-приложения, который заканчивается на /exec.
https://script.google.com/macros/s/AKfycbXXXXXXXXXXXX/exec
	

  





6
	Настройте робота в нужной воронке Bitrix24
	1. Откройте CRM → Сделки.
2. Выберите нужную воронку.
3. Откройте вкладку «Роботы».
4. Найдите стадию, при попадании на которую нужно отправлять данные.
5. Под этой стадией нажмите «Создать» / «Добавить робота».
6. Найдите и добавьте действие «Исходящий вебхук».
7. Установите «Когда: Сразу» и «По очереди: Независимо от других роботов».
8. Проверьте, что условие относится к правильной воронке и стадии.
6.1. Готовый шаблон ссылки для робота 
ССЫЛКА_APPS_SCRIPT?company={{Компания: Название}}&company_phone={{Компания: Телефон}}&company_email={{Компания: E-mail}}&contact={{Контакт: Фамилия}}%20{{Контакт: Имя}}%20{{Контакт: Отчество}}&contact_phone={{Контакт: Телефон}}&contact_email={{Контакт: E-mail}}
	
Нужные поля прописываются вручную, меняются в зависимости от потребностей. Тех.название выбирается любое короткое





Оно должно быть:
* латиницей;
* без пробелов;
* лучше маленькими буквами;
* слова разделяются нижним подчёркиванием.

Например нужно выгружать поле адрес обьекта


ССЫЛКА_APPS_SCRIPT?object_address
далее выбиреаем напротив тех названия тремя точками нужно значение для выгрузки 
  

Сохранить и протестировать 1-2 раза
