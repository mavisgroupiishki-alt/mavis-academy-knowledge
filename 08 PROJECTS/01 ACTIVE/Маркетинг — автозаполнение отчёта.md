# Маркетинг — автозаполнение отчёта

## Цель
Автоматически заполнять маркетинговую таблицу данными из Bitrix24 по единой логике без ручного переноса цифр.

## Текущий режим
Автозапуск: **ежедневно в 09:00 по Минску**.

## Принципы
- выводить все даты;
- если факта нет — сохранять дату и ставить 0;
- сохранять единый формат;
- продажи, сделки и лиды рассчитывать по согласованной логике;
- плановые показатели остаются редактируемыми вручную.
