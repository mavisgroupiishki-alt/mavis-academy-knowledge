# Инструкция договор

## Первичный источник

[Открыть документ на Google Drive](https://docs.google.com/document/d/135z2FF8EFG4mUKJ5_mB7vMSHM1Li21JM/edit?usp=drivesdk)

## Полный текст из источника

СОЗДАНИЕ ДОГОВОРА-СЧЕТА ДЛЯ КЛИЕНТА
заходим в компанию для заполнения реквизитов
Нажав на реквизиты нажимаем подробно
Вносим реквизиты компании по подсказкам (обязательно нажать сохранить)
Возвращаемся из компании в сделку, нажимаем создать договор и выбираем предмет договора (в поле создать договор нажать «ДА»)
Далее у вас появится справа договор который можно открыть и скачать
Далее, для создания счета, нажимаем документ- выбираем нужный счет-заказ исходя из вашей услуги он также отобразится рядом с договором и его можно будет скачать
