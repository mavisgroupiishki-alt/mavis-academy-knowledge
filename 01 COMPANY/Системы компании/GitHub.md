# GitHub

## Роль
Единый источник правды для кода AI-проектов и автоматизаций.

## Что будем хранить
- исходный код;
- версии;
- README;
- changelog;
- конфигурации без секретов;
- issues / технические задачи.

## Правило
Секреты, API-ключи и пароли в репозитории не хранятся.
