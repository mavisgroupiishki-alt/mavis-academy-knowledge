# SOP — Правила Mavis Knowledge

## Основные правила
- одна сущность = одна заметка;
- не создавать дубли с разным написанием;
- использовать внутренние ссылки;
- секреты не хранить в заметках;
- большие выгрузки не копировать без необходимости;
- фиксировать принятые решения;
- устаревшее переносить в архив, а не стирать без причины;
- важные изменения сопровождать датой.
