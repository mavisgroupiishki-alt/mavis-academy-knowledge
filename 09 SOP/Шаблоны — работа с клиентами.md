## Полный текст из источника

**Шаблоны хода работы по продуктам для седок в работе:**

*Формат: скопировать, адаптировать под конкретную сделку и отправить клиенту в мессенджер.*

**Задача: быстро перезапустить коммуникацию по всем активным и зависшим сделкам, где клиент давно не получал понятный ход работы.**

 

# **1\. Правила перед отправкой клиенту**

• Открыть карточку сделки: КП, товары, комментарий менеджера, переписку, счета, файлы клиента.

• Определить по каждому продукту: что уже есть, чего не хватает, какой следующий шаг и кто должен его сделать.

• Не спрашивать клиента заново то, что уже есть в карточке. В сообщении писать: “по нашей информации уже есть...”

• Если клиент завис из\-за нас — признать нейтрально: “***обновляю ход работы и фиксирую следующий шаг***”.

• Если клиент завис из\-за документов/оплаты — писать конкретно, что блокирует процесс и до какого срока нужно закрыть.

• Отправить сообщение в мессенджер клиента. Документы, счета и перечни копий дополнительно продублировать на email.

• После отправки: вставить текст сообщения в комментарий сделки и поставить дела по дедлайнам.

## **Мини-структура любого сообщения**

·   	1-й абзац: “обновляю ход работы по вашим документам”.

·   	Блок “Что уже есть”.

·   	Блок “Что сейчас не хватает / что нужно от вас”.

·   	Блок “Что делаем мы”.

·   	Сроки и предупреждение: “если закрываем это вовремя, идём по плану; если нет \- сроки сдвигаются”.

### **Универсальное начало и завершение для любой сделки в работе**

| \[Имя\], добрый день. Обновляю ход работы по вашим документам и фиксирую, что сейчас есть в работе, а что блокирует дальнейшее движение.   Сейчас в работе: \[перечислить продукты\].   Ниже коротко: что уже есть, что нужно от вас и что делаем мы. |
| :---- |

| Чтобы не сдвигать сроки, прошу сегодня/завтра до \[время\] закрыть пункты, которые указаны в блоке “от вас”.   После вашего ответа мы сразу обновим график работ и зафиксируем следующий шаг по каждому продукту. |
| :---- |

# **Что эксперт фиксирует в Bitrix после отправки**

• Скопировать отправленный клиенту текст в комментарий сделки.

• Поставить дело на дату дедлайна клиента.

• Если клиент должен оплатить — поставить задачу “ожидаем оплату”.

• Если клиент должен прислать документы — поставить задачу “проверить документы клиента”.

• Если клиент иногородний и нужна бумага — поставить задачу на сверку папки за 2 дня до подачи/аттестации.

• Если по ISO/охране труда есть замечания — зафиксировать причину и поставить задачу на устранение.

• Услугу закрывать только после фактического результата: свидетельство/аттестат/сертификат получен или выписан.

# **2\. Шаблон: комплекс услуг**

*Комплекс: свидетельство технической компетентности \+ аттестация \+ ISO 9001 \+ сертификат по охране труда / ISO 45001 \+ возможный подбор/аттестация специалиста.*

### **Сообщение клиенту:**

| \[Имя\], добрый день. Обновляю ход работы по вашему комплексу документов: свидетельство технической компетентности, аттестация, ISO 9001, сертификат по охране труда / ISO 45001, \[подбор/аттестация специалиста — если есть\].   Что уже есть: — по специалистам: \[ФИО/должность/что закрывает\]; — по подбору: \[кого подбираем мы / кого ищете вы / срок\]; — по средствам измерений: \[что есть / что не хватает / что нужно сверить\]; — по ISO/охране труда: \[есть список сотрудников / нужны данные по комиссии / нужен бриф\]; — по счетам: \[что оплачено / что не оплачено\].   От вас сейчас нужно: 1\. До \[дата/время\] — закрыть оплату счетов: \[перечислить счета\]. 2\. До \[дата/время\] — прислать/подтвердить информацию по средствам измерений: что есть, что берёте в аренду, чего не хватает. 3\. До \[дата/время\] — прислать список сотрудников для ISO 9001\. 4\. До \[дата/время\] — дать 3 ФИО и должности для комиссии по охране труда, если оформляем сертификат по охране труда / ISO 45001\. Один из них — директор. 5\. До \[дата/время\] — прислать 2 фото 3×4 см по аттестации специалиста \[ФИО\], если эта услуга есть. 6\. До \[дата\] — оформить/перевести \[ФИО\] на должность \[должность\], если это требуется для аттестации.   С нашей стороны: — сверяем средства измерений и заказываем недостающие счета; — запускаем техкарты / Стройдок / пошлины после оплаты; — готовим документы по свидетельству технической компетентности; — готовим документы на аттестацию; — параллельно запускаем ISO 9001 и сертификат по охране труда / ISO 45001; — контролируем выезд, подачу, замечания и итоговую выписку документов.   Срок: если все оплаты и данные закрываем вовремя, ориентир: свидетельство технической компетентности — до 10 дней; ISO 9001 / сертификат по охране труда / ISO 45001 — до 2 недель; аттестация — ориентировочно до 3 недель. Если замечания по аттестации или ISO/охране труда зависят от ваших данных, срок выписки сертификатов может сдвинуться. |

# **3\. Шаблон: СПК (свидетельство технической компетентности) / периодическая оценка СПК**

### Сообщение клиенту

| \[Имя\], добрый день. Обновляю ход работы по свидетельству технической компетентности / периодической оценке.   Что уже есть: — специалисты по основному месту работы: \[ФИО 1\], \[ФИО 2\]; — орган: \[БИСП / Стройкомплекс, если уже определён\]; — средства измерений: \[есть / частично есть / нужно сверить\]; — техкарты / стройдок: \[нужны / заказаны / оплачены / не оплачены\]; — пошлина: \[оплачена / не оплачена\].   От вас сейчас нужно: 1\. До \[дата/время\] — отправьте, пожалуйста, информацию по людям (диплом, трудовую), если совместительство \- приказ. 2\. До \[дата/время\] — отметить по перечню средств измерений: что есть своё, что можете взять в аренду, чего не хватает. 3\. До \[дата/время\] — оплатить \[пошлину / техкарты / стройдок / средства измерений\]. Дополнительно: за 2 дня до даты подачи отправить почтой/курьером бумажные заверенные копии и подписанные документы, если компания не из Минска.   С нашей стороны: — сверяем документы по людям (подбор) — сверяем перечень средств измерений; — по недостающим позициям заказываем счета; — контролируем оплату техкарт / Стройдоков / пошлин; — готовим документы для БИСП или Стройкомплекса; — контролируем подачу и получение свидетельства.   Срок: если сегодня-завтра закрываем оплату и данные по людям, процедуру можно пройти ориентировочно за неделю. Если оплата или информация задерживаются, срок получения может сдвинуться. |

# **4\. Шаблон: аттестация компании**

### Сообщение клиенту

| \[Имя\], добрый день. Обновляю ход работы по аттестации компании.   Что уже есть: — виды работ по КП: \[проговорить в звонке\]; — нужные специалисты и кто их закрывает: \[перечислить по КП \- ФИО \- должность\]; — кого переводим: \[ФИО / новая должность / срок\]; — кого подбираем мы: \[должность / срок\]; — кого ищете вы: \[должность / срок\]; — предварительная дата аттестации / подачи: \[дата, если есть\].   От вас сейчас нужно: 1\. До \[дата\] — оформить/перевести \[ФИО\] на должность \[прораб / главный инженер / заместитель директора — главный инженер\]. 2\. Если директор закрывает прораба или главного инженера: в трудовой книжке должна быть запись о переводе на нужную строительную должность. Дополнительно оформляется трудовой договор/контракт по внутреннему совмещению, чтобы он продолжал выполнять функции директора. Пример оформления направим отдельно. 3\. До \[дата/время\] — прислать недостающие документы по специалистам: \[перечислить\]. 4\. Если компания не из Минска — бумажные заверенные копии и подписанные документы отправить почтой (первым классом) /курьером не позднее чем за 3 дня до даты подачи/аттестации.   С нашей стороны: — проверяем на соответствие специалистов для подачи; — готовим документы для Белстройцентра; — подаем документы и контролируем замечания; — контролируем получение аттестата.   Срок: Если специалисты и документы готовы, ориентир по аттестации — до 2 недель. Аттестат подписывается по пятницам, в реестре обычно появляется во вторник–среду после подписания.  |

Прислать недостающие документы: \[что именно\]. 2\. Прислать паспортные данные специалиста (последняя страница \+ прописка). # **9\. Ситуативные шаблоны:**

### Напоминание по оплате и документам

| \[Имя\], добрый день. Напоминаю, сегодня дедлайн по \[оплате / документам / средствам измерений\]. Пришлите, пожалуйста, \[платёжку / документы / ответ по перечню\] до \[время\], чтобы мы не сдвигали сроки. |
| :---- |

 

### **Если клиент не отвечает**

| \[Имя\], мы направили вам информацию и сейчас не получаем ответ по \[оплате / документам / данным\]. Фиксирую, что без этого мы не можем двигаться дальше по \[подаче / выезду / получению документа\].   Прошу сегодня до \[время\] прислать \[что именно\]. Если не успеваем закрыть этот пункт, сроки получения документов сдвигаются. |
| :---- |

 

### **Если срывается выезд по ISO / охране труда**

| \[Имя\], сегодня крайний срок оплаты пошлины. Если оплату не закрываем, выезд по ISO 9001 / сертификату по охране труда / ISO 45001 придётся переносить.   В таком случае срок получения сертификата сдвинется, а подготовленные документы могут потребовать актуализации. Прошу прислать платёжку сегодня до \[время\]. |
| :---- |

 

### **Если клиент говорит, что нет денег**

| \[Имя\], понимаю. Тогда предлагаю зафиксировать реальную дату оплаты, чтобы мы корректно перенесли выезд/подачу и не потеряли подготовленный пакет документов.   Самый критичный счёт сейчас — \[название счёта\], потому что без него мы не сможем \[поставить выезд / подать документы / получить свидетельство\]. Предлагаю закрыть его в первую очередь, остальные — по согласованному графику.   Подскажите, какую дату оплаты фиксируем? |
| :---- |
