# Офис-менеджер: документы, оплаты, аренда и контроль задач

## Роль

Офис-менеджер поддерживает управляемый документооборот: каждая задача имеет документ, статус, срок и следующее действие. Этот регламент не разрешает самостоятельно менять содержание договоров, финансовые условия или кадровые данные.

## Ежедневный контроль

| Проверка | Действие | Результат |
| --- | --- | --- |
| Проект «Акты Счета» | Проверить просроченные задачи и задачи без следующего действия. | По каждой зависшей задаче назначен звонок, письмо, получение оригинала или эскалация. |
| Входящая корреспонденция | Забрать и зарегистрировать письма по принятому внутреннему порядку. | Оригиналы не остаются без связанной задачи. |
| Платёжный календарь | Отразить поступления и списания, сверить остатки с банком. | План и факт не расходятся без объяснения. |
| Офис | Проверить расходные материалы и согласовать закупки. | Нет внеплановой закупки без основания. |
| Новые компании | Выгрузить и импортировать лиды только по утверждённому шаблону. | Лиды появляются в CRM с назначенным ответственным. |

### Порядок ежедневной проверки

1. Открыть проект «Акты Счета» и просмотреть все задачи без статуса и с просроченным следующим действием.
2. По каждой задаче определить **конкретную** ветку: подготовить документ, ожидать оплату, распечатать, передать в конверт, отправить, дождаться оригинала или эскалировать ответственному.
3. Проверить входящую почту и фактические оригиналы. Каждый полученный документ привязать к соответствующей задаче и карточке, а не хранить отдельной стопкой.
4. Сверить календарь платежей с банковской выпиской. Не менять назначение, сумму или получателя без подтверждения уполномоченного сотрудника.
5. Проверить запас расходных материалов и оборудование в аренде: есть ли договор, счёт, подтверждение оплаты, дата передачи и возврата.
6. Проверить выгрузку/импорт новых компаний по утверждённой форме, чтобы лид не остался без ответственного.

## Маршрут актов, договоров и счетов

**Подготовлен документ → печать → конверт → отправка → контроль возврата → архив.**

1. Начинайте работу только после того, как документ сформирован и прошёл требуемую проверку.
2. При личном получении фиксируйте обещанную дату и переводите задачу в соответствующую ветку, не имитируя отправку.
3. После фактической почтовой отправки укажите дату, способ и подтверждение отправки; назначьте контроль возврата по внутреннему сроку.
4. Для возврата оригинала используйте последовательность: email-напоминания → звонки с записью результата → письмо с описью, если это предусмотрено регламентом.
5. Вернувшийся оригинал проверяется, фиксируется в комментарии и помещается в архив по диапазону номеров.

### Статусы проекта «Акты Счета»

| Статус | Когда использовать | Обязательная фиксация |
| --- | --- | --- |
| Новые | Документ или задача поступили в работу. | Что нужно подготовить, кто ответственный, срок. |
| Сделаны / оплатили | Документ сформирован или подтверждена оплата. | Номер документа/платежа и следующий шаг. |
| Распечатано | Документ распечатан и готов к отправке. | Количество экземпляров и способ передачи. |
| Конверт | Оригиналы собраны в конверт. | Адресат, содержимое, дата готовности. |
| Отправлены | Документы фактически переданы почте/курьеру. | Дата, способ, трек-номер при наличии, дата контрольной проверки. |
| Личное получение | Клиент или сотрудник забирает комплект сам. | Кто забирает и согласованная дата. |
| Email / ручная обработка | Нужен электронный или нестандартный маршрут. | Причина, вложения, следующий контакт. |
| Звонок / ожидание возврата | Требуется напомнить об оригинале. | Дата контакта, результат, дата следующего касания. |
| Инвентаризационное письмо | Применяется только по утверждённому регламенту после напоминаний. | Основание, отправленные документы и подтверждение. |
| Архив | Оригинал получен и проверен. | Номер папки/диапазон, дата архивации. |

### Полная логика возврата оригиналов

1. После отправки поставить контрольную дату возврата по внутреннему сроку (в рабочем чек-листе — через 14 дней).
2. Если оригинал не вернулся, отправить первое email-напоминание и зафиксировать его в задаче.
3. Если ответа нет, повторить напоминание, затем сделать звонок. В комментарии записать дату, с кем говорили и обещанный срок.
4. Если оригинал всё ещё не получен, повторить звонок в рамках внутреннего регламента и только затем направлять инвентаризационное письмо с описью — когда этот способ согласован.
5. После возврата сверить подписи, печати и комплектность. Если есть ошибка, не архивировать: вернуть задачу в ветку исправления.
6. Архивировать по утверждённой нумерации папок; электронную копию прикрепить к карточке.

## Платёжный календарь

| Период | Что сделать |
| --- | --- |
| До начала месяца | Собрать плановые расходы, внести обязательства и распределить согласованные расходы по датам. |
| Ежедневно | Отразить выписку банка, проверить остатки и подготовить платежи на согласование. |
| Перед оплатой | Перепроверить платёжное поручение, дождаться согласования уполномоченного руководителя. |
| После оплаты | Убедиться, что платёж исполнен; при отклонении выяснить причину и исправить только подтверждённую ошибку. |

Не храните в учебной базе личные суммы, реквизиты карт или банковские данные сотрудников.

## Аренда инструментов

| Шаг | Действие |
| --- | --- |
| Заявка | Создать строку в рабочей таблице: номер, дата, компания, инструмент, оплата и срок. |
| Договор | В карточке указать только требуемые поля договора, сохранить и сформировать документы. |
| Оплата | Сопоставить сообщение об оплате с заявкой, затем обновить статусы по внутреннему правилу. |
| Передача | Счёт передать эксперту по принятому каналу; договор — после подтверждённой оплаты. |
| Завершение | После возврата оригинала зафиксировать комментарий, обновить таблицу и архивировать задачу. |

### Обязательные поля рабочей таблицы аренды

| Поле | Что вносить |
| --- | --- |
| Номер и дата | Номер строки/договора и дата создания. |
| Клиент | Наименование компании и связанная CRM-карточка. |
| Инструмент | Точный прибор и количество; не писать общее «оборудование». |
| Документы | Статус счёта, договора и акта передачи. |
| Оплата | Только подтверждённый статус оплаты, без банковских реквизитов. |
| Срок | Дата передачи, плановая дата возврата, ответственный. |
| Итог | Фактический возврат, комментарий о комплектности и архив. |

## 1С: ориентир по акту

Оформитель создаёт акт. Офис-менеджер использует счёт-заказ как источник номера, услуги, суммы, УНП и номера договора, проверяет проведение документа, печать и прикрепление финальной версии к задаче. При расхождении данных — не исправляет их сам, а возвращает ответственному за оформление.

### Последовательность подготовки акта

1. Открыть согласованный счёт-заказ и сверить контрагента, услугу, сумму, УНП и договор.
2. Создать акт только на основании этих подтверждённых данных.
3. Проверить номер, дату, услуги, сумму, реквизиты и основание до проведения документа.
4. Провести документ, сформировать печатную форму и проверить, что в печать не попал черновик.
5. Сохранить финальную версию в утверждённом месте, прикрепить к задаче и перевести её в следующий корректный статус.
6. Если данные счёта-заказа, CRM и 1С расходятся — остановить выпуск и вернуть на исправление владельцу данных. Не исправлять договорные условия «по памяти».
