# SOP — Работа с Inbox

## 1. Новая информация
Новая непроверенная информация попадает в `99 INBOX`.

## 2. Проверка
Определить:
- источник;
- актуальность;
- к какому типу знаний относится;
- не существует ли уже такая сущность;
- нет ли конфликта с действующим решением.

## 3. Классификация
После проверки:
- проект → `08 PROJECTS`;
- решение → `11 DECISIONS`;
- инструкция → `09 SOP`;
- данные/метрики → `10 DATA & ANALYTICS`;
- техническая сущность → `06 BITRIX24` или `07 AI & AUTOMATION`.

## 4. Завершение
Добавить ссылки на связанные сущности и убрать исходный материал из активного Inbox.
