# Mavis Academy — Конституция

## Принципы

### I. Первичный источник важнее выжимки
Порядок работы эксперта в каждой продуктовой плитке ДОЛЖЕН быть получен из раздела «Ход работы эксперта» соответствующего паспорта. Краткая карта может помогать с навигацией, но не заменяет этапы, условия и документы из паспорта.

### II. Роли не смешиваются
Менеджерская и экспертная версии одной темы ДОЛЖНЫ показывать разные действия и разные проверки знаний. Общее ядро допускается только для понятия, людей и инструментов.

### III. Стажировка следует утверждённому плану
Каталог стажёра ДОЛЖЕН повторять пункты и задания таблицы «Стажировка Отдел Продаж» по дням. Стажёру не показываются справочники и рабочие плитки сотрудников вне этого плана.

### IV. Сохраняемая редактура не теряет материал
Изменения руководителя ДОЛЖНЫ попадать в постоянное хранилище либо явно завершаться ошибкой; нельзя сообщать об успешном сохранении без подтверждённого ответа сервера.

## Ограничения

- Не изменять исходные паспорта и Google-таблицу без отдельного запроса.
- Не сокращать экспертные этапы в текст, который меняет их смысл.
- Не публиковать персональные данные вне материалов, которые пользователь прямо разрешил публиковать.

## Рабочий процесс

Перед изменением сверяется код, паспорт или таблица-источник. После изменения проверяются сценарии менеджера, эксперта и стажёра, а также тесты и доступ к источнику.

## Governance

Конституция имеет приоритет над реализациями Academy. Изменение принципа требует обновления версии.
