# Спецификация: Полная редакторская переработка источников

**ID:** 001-source-curation  
**Статус:** Approved  
**Создана:** 2026-11-09

## Цель

Перенести доступные материалы пользователя в Academy как понятные уроки и рабочие таблицы, распределив их по ролям без дублей.

## Требования

1. Для каждого источника фиксируется статус: добавлен, частично добавлен или недоступен.
2. Каждый урок объясняет назначение, входные данные, порядок действий, результат и ограничения.
3. Табличные правила отображаются таблицами, если это повышает понятность.
4. Материалы назначаются менеджеру, эксперту и руководителю; стажёр видит только программу дня.
5. Поиск находит заголовок и текст новых уроков.

## Критерии приёмки

- [ ] В уроках нет технических имён файлов, необъяснённых сокращений или сырого табличного текста.
- [ ] Дубли объединены.
- [ ] Недоступные источники перечислены пользователю с точным URL и технической причиной.
