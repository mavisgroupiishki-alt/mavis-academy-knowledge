# Технический план: общая база и тесты для сотрудников

**Спека:** [spec.md](spec.md)
**Создан:** 2026-11-10

## Архитектура

Один набор рабочих ролей (`manager`, `expert`, `leader`) становится источником прав для каталога и редакторов. Клиент открывает единый каталог тестов на основе уже существующих практик плиток. Сервер зеркально проверяет те же роли для чтения и сохранения.

## Ресурсы по блокам

| Блок | Модель | Скиллы | Агенты | Обоснование |
|---|---|---|---|---|
| Роли и API | balanced/medium | systematic-debugging | — | Нужно синхронно изменить клиентские и серверные проверки. |
| Каталог тестов | balanced/medium | frontend-design | — | Переиспользуется существующая практика без новой модели данных. |
| Проверка | fast/low | qa-testing-playwright, verification-before-completion | — | Нужны тесты и проверка реального интерфейса. |

## Риски

- Расхождение клиентских и серверных ролей может показывать кнопку без возможности сохранить. Митигируется контрактным тестом и изменением обоих уровней.
- Полный доступ к результатам стажёров не нужен для базы и не включается.
