# Технический план: учебные презентации и полный импорт новых источников

## Архитектура

Источники хранятся как Markdown в разрешённых каталогах базы и читаются существующим `/api/course/document`. В JavaScript добавляется состояние `presentation`, которое использует тот же выбранный курс, роль и источники, что и читатель курса. Презентация строится из четырёх опорных слайдов и одного слайда на каждый источник; исходник загружается через уже защищённый маршрут, без отдельного сетевого API.

## Риски и защита

- Большие исходники могут быть неудобны в одном слайде: презентация показывает их как прокручиваемый первоисточник, а не пытается искусственно обрезать.
- Условие `is_safe_knowledge_path` допускает только Markdown из известных разделов; новые файлы хранятся там же.
- Телефоны выводятся только по явному актуальному разрешению пользователя и только в маршруте Госпромнадзора.
- Инструкция передачи дел не содержит логинов и паролей: вместо них — проверяемая безопасная процедура передачи.
