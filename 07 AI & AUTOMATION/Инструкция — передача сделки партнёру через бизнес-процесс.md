# Передача сделки партнёру через бизнес-процесс Bitrix24

## Назначение

Этот сценарий передаёт партнёру данные сделки при наступлении выбранной стадии. Его настраивает сотрудник с правами на бизнес-процессы. Перед запуском согласуйте владельца процесса, воронку, получателя и состав передаваемых полей.

## Схема

**Нужная воронка → условие «стадия равна» → почтовое сообщение → тестовая сделка → журнал результата.**

## Настройка

1. Откройте в Bitrix24 раздел «Бизнес-процессы» и выберите процессы CRM для сделок.
2. Создайте шаблон, задайте понятное название и описание передачи.
3. В настройке отображения оставьте только ту воронку, для которой предназначен процесс.
4. Между «Началом» и «Концом» добавьте условие по полю «Стадия» и выберите нужную стадию именно в целевой воронке.
5. В ветку условия добавьте действие «Почтовое сообщение».
6. Укажите согласованную корпоративную почту отправителя и получателя. Не вставляйте в шаблон личные адреса или данные, не согласованные для передачи.

## Поля сообщения

| Поле | Для чего передаётся |
| --- | --- |
| Название сделки | Идентификация запроса. |
| Компания и контакт | Связь с клиентом по согласованному сценарию. |
| Телефон и email | Только при законном основании и согласованной передаче. |
| Вид работ | Понимание предмета сделки. |

Каждое поле подставляйте через селектор Bitrix24, а не вручную в виде шаблонного текста.

## Проверка перед запуском

- создать тестовую сделку без данных реального клиента;
- перевести её в целевую стадию;
- проверить получателя, тему, подстановку полей и отсутствие лишних персональных данных;
- зафиксировать владельца процесса и способ отключения;
- только после проверки включать сценарий в рабочей воронке.

## Удаление или изменение

Изменять и удалять процесс должен его владелец или администратор после проверки, какие воронки и сделки он затрагивает. Не удаляйте действующий процесс без резервного сценария и записи причины.
