# GitHub — стандарты репозиториев

## Для каждого проекта
- README.md
- src/
- .env.example
- requirements.txt или pyproject.toml
- Dockerfile при необходимости
- CHANGELOG.md
- docs/
- tests/

## Обязательно
- никаких реальных секретов в репозитории;
- понятное название проекта;
- ссылка на карточку проекта в Obsidian;
- версия production-кода должна быть определима.
