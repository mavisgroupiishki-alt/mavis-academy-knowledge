# Как работать с AI-процессами Mavis

## Ежедневная схема

1. Пользователь работает через Telegram-бота, дашборд или Bitrix24.
2. Сервис Render принимает запрос и выполняет обработку.
3. Данные сохраняются в подключённое хранилище/сервис.
4. Результат проверяется в интерфейсе; критичные изменения проходят согласование.
5. Исходный код и изменения находятся в GitHub.

## Какие сервисы обнаружены

- **mavis-vibecode-relay** — relay для запросов VibeCode.
- **transcribat** — сервис транскрибации.
- **mavis-operational-dashboard** — управленческий дашборд продаж, производства, NPS и расшифровок.
- **mavis-registry** — генератор/реестр документов и коммерческих предложений.
- **mavis-payment-schedule** — график платежей.
- **mavis-task-tracker** — трекер задач.
- **mavis-task-bot** — бот задач.
- **mavis-bitrix-expert-assistant** — Bitrix-ассистент: письма, документы клиентов, задачи экспертам и контроль актов.
- **iso-smk-1 / iso-smk-rar / iso-smk-kristina / iso-smk** — отдельные сервисы направления ISO/СМК.
- **sales-analytics** — аналитика продаж.
- **marketing** — маркетинговый контур.
- **VAKANSII-1** — контур вакансий.

## Как вносить изменения

1. Найти нужный сервис в этом разделе.
2. Открыть его репозиторий GitHub и проверить README, Dockerfile, requirements.txt или package.json.
3. Изменения делать отдельной веткой и через Pull Request.
4. После проверки дождаться deploy в Render.
5. Проверить URL сервиса и health endpoint.
6. Проверить последние логи и события Render.
7. Если deploy неудачен — не менять секреты вслепую; сначала проверить build/start command и переменные окружения.

## Секреты

API-ключи, пароли, токены Bitrix, почты и Render Environment Variables не хранятся в Obsidian или GitHub. Их место — только защищённые переменные окружения Render/Keychain.

## Ограничения текущей инвентаризации

GitHub-коннектор сейчас не вернул список репозиториев. Поэтому описания Render-сервисов подтверждены метаданными Render, а подробные README подтверждены для доступных репозиториев. Для остальных нужна повторная авторизация GitHub.
