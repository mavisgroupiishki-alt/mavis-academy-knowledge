# Mac mini — будущий AI server

## Роль
Постоянный корпоративный сервер 24/7 для Mavis AI, базы знаний, интеграций и автоматизаций.

## Планируемые компоненты
- Obsidian server/headless copy;
- Mavis AI Agent;
- Docker;
- планировщик;
- сервис логов;
- резервное копирование;
- интеграционные сервисы;
- при необходимости локальные AI-модели.

## Принцип
Рабочий MacBook не должен быть обязательным для работы корпоративного AI.
