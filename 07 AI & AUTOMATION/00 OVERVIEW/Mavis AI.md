# Mavis AI

## Роль
Корпоративный AI-слой над базой знаний Mavis Knowledge и подключёнными системами компании.

## Планируемые источники
- Obsidian / Mavis Knowledge
- Bitrix24
- GitHub
- Google Drive / Bitrix Disk
- внутренние API и сервисы

## Основные функции
- поиск и ответы по знаниям компании;
- поддержание технической документации;
- анализ связей между проектами;
- подготовка изменений;
- диагностика автоматизаций;
- контроль актуальности знаний.

## Безопасность
Критичные изменения должны проходить через подтверждение человека.
